# BIC Model Selection Simulation

This folder contains the BIC model-selection experiment. It reuses the data
generated by `../parameter_recovery`.

## Design

- Use the existing generated data in `../parameter_recovery/data/generated`
- Only use scenarios with `n = 1000`
- True dimensions: `K1 = K2 = 2, 3, 4`
- Item blocks: `J1 = J2 = 24, 36`
- 100 replicates per true scenario
- Candidate fitted dimensions: `K1, K2 = 1, 2, 3, 4, 5`

Total array size:

```text
3 true K values * 2 J values * 100 replicates * 25 fitted (K1,K2) pairs = 15000 tasks
```

The MCMC defaults match the main simulation:

```text
iteration = 3000
burnin = 2000
```

## Run

From `simulation/bic_model_selection`:

```bash
sbatch slurm/run_bic_array.sbatch
sbatch slurm/aggregate_bic_selection.sbatch
```

Or submit the dependent aggregation automatically:

```bash
bash run_all_bic.sh
```

If `../parameter_recovery/data/generated/manifest.csv` does not exist
yet, first run the parameter-recovery data-generation job:

```bash
cd ../parameter_recovery
sbatch slurm/generate_data.sbatch
```

The candidate fits load the shared EACDM implementation from `../../src/`.

## Outputs

Each candidate fit writes:

```text
result/bic_fits/scenario_02_n1000_J24_trueK2/replicate_001/fit_K1_1_K2_1.rds
```

Aggregation writes:

```text
result/summary/bic_all_fits.csv
result/summary/bic_best_by_replicate.csv
result/summary/bic_selection_summary.csv
result/summary/bic_selected_model_counts.csv
result/summary/bic_selection_summary.rds
```
