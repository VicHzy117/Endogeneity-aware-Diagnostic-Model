# Simulation Code

This folder contains all simulation code for the proposed EACDM:

- `parameter_recovery/`: parameter-recovery simulation used for the main
  simulation table.
- `bic_model_selection/`: BIC-based selection of latent dimensions for EACDM.
- `convergence_diagnostics/`: multi-chain convergence diagnostics and running
  Gelman--Rubin figures used in the supplement.

Each subfolder has its own README and Slurm scripts.
