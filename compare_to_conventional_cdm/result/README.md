# Lightweight Results

This folder stores lightweight summary outputs used in the Supplementary
Material.  Full MCMC fit files are excluded from the GitHub package because they
are large and can be regenerated by the scripts in `../code/` and `../slurm/`.

The key outputs are in `modal_k_summary/`:

- `eacdm_best_k_counts.csv`
- `conventional_cdm_best_k_counts.csv`
- `EACDM_blockwise_Q.png`
- `conventional_CDM_blockwise_Q.png`
